
# Laravel Asset Bundling with Vite: Documentation

লারাভেল অ্যাপ্লিকেশনে সিএসএস (CSS) এবং জাভাস্ক্রিপ্ট (JS) ফাইলগুলোকে অপ্টিমাইজড উপায়ে ম্যানেজ করার জন্য বর্তমানে **Vite** (উচ্চারণ: ভিট/ভাইট) ব্যবহার করা হয়। এটি আগে ব্যবহৃত 'Laravel Mix' বা 'Webpack'-এর একটি দ্রুত এবং আধুনিক বিকল্প।

---

## ১. ভিট (Vite) কী এবং কেন এটি প্রয়োজন?

**Vite** হলো একটি আধুনিক ফ্রন্টএন্ড বিল্ড টুল যা ডেভেলপমেন্টের সময় অত্যন্ত দ্রুত গতিতে কাজ করে। এর প্রধান কাজ হলো:

* **Asset Bundling:** অনেকগুলো ছোট ছোট সিএসএস এবং জেএস ফাইলকে একত্রে বড় ফাইল বা বান্ডেল তৈরি করা যাতে প্রোডাকশনে পেজ দ্রুত লোড হয়।
* **Hot Module Replacement (HMR):** কোডে কোনো পরিবর্তন করলে ব্রাউজার রিফ্রেশ ছাড়াই অটোমেটিক আপডেট দেখা যায়।
* **Production Optimization:** প্রোডাকশনে ফাইলগুলোকে কম্প্রেস বা মিনিফাই করে সাইজ কমিয়ে ফেলে।

## ২. লারাভেলে ভিটের কনফিগারেশন (`vite.config.js`)

লারাভেল ইনস্টল করার পর রুট ডিরেক্টরিতে `vite.config.js` ফাইলটি থাকে। এটি লারাভেলকে বলে দেয় কোন ফাইলগুলো বান্ডেল করতে হবে।

### ফাইলের গঠন:

```javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'], // ইনপুট ফাইলসমূহ
            refresh: true, // কোড সেভ করলে অটো রিফ্রেশ হবে
        }),
    ],
});

```

## ৩. ব্লেড টেমপ্লেটে ভিটের ব্যবহার (`@vite` Directive)

আপনার অ্যাপ্লিকেশনে সিএসএস এবং জেএস ফাইলগুলো লোড করার জন্য ব্লেড ফাইলে সরাসরি `@vite` ডিরেক্টিভ ব্যবহার করতে হয়।

```blade
<!DOCTYPE html>
<html>
<head>
    <title>My Laravel App</title>
    {{-- Vite Directive --}}
    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
<body>
    <h1>Vite is working!</h1>
</body>
</html>

```

## ৪. ডেভেলপমেন্ট এনভায়রনমেন্ট সেটআপ

ভিট ব্যবহার করার জন্য আপনার পিসিতে **Node.js** এবং **NPM** ইনস্টল থাকতে হবে।

### ভার্সন চেক করার কমান্ড:

```bash
node -v
npm -v

```

### প্রজেক্টে ভিট রান করার কমান্ড:

ডেভেলপমেন্টের সময় নিচের কমান্ডটি চালিয়ে রাখতে হয় যাতে আপনার পরিবর্তনগুলো তাৎক্ষণিকভাবে ব্রাউজারে দেখা যায়:

```bash
npm install   # প্রথমবার প্যাকেজ ইনস্টলের জন্য
npm run dev   # ডেভেলপমেন্ট সার্ভার রান করার জন্য

```

প্রোডাকশনের জন্য ফাইলগুলো বিল্ড করতে:

```bash
npm run build

```

## ৫. লারাভেল ভিট প্লাগইন

লারাভেলের জন্য একটি নির্দিষ্ট ভিট প্লাগইন (`laravel-vite-plugin`) কাজ করে। এটি লারাভেলের ইন্টারনাল স্ট্রাকচারের সাথে ভিটের সেতুবন্ধন তৈরি করে, ফলে আমরা সহজেই রাউট বা ব্লেড ফাইল থেকে অ্যাসেটগুলো এক্সেস করতে পারি।

---

## সারসংক্ষেপ (Key Points)

* **Fast Reload:** ভিটের মাধ্যমে ডেভেলপমেন্ট অনেক দ্রুত হয়।
* **Default Support:** লারাভেল ৯.এক্স-এর পরবর্তী ভার্সনগুলোতে এটি ডিফল্ট হিসেবে থাকে।
* **Config:** `vite.config.js` ফাইলের মাধ্যমে আমরা নতুন ফাইল বান্ডেলিংয়ে যুক্ত করতে পারি।
