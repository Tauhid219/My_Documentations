Write a PHP script to get the PHP version and configuration information. 

PHP-তে আপনার সার্ভারের ভার্সন এবং কনফিগারেশন ডিটেইলস জানার জন্য সবচেয়ে সহজ এবং কার্যকর উপায় হলো `phpinfo()` ফাংশনটি ব্যবহার করা।

নিচে এর স্ক্রিপ্ট এবং ব্যবহারবিধি দেওয়া হলো:

### ১. পিএইচপি স্ক্রিপ্ট (PHP Script)

একটি নতুন ফাইল তৈরি করুন (যেমন: `info.php`) এবং নিচের কোডটি লিখুন:

```php
<?php
// এই ফাংশনটি পিএইচপি ভার্সন এবং সব কনফিগারেশন দেখাবে
phpinfo();
?>

```

---

### ২. কিভাবে কাজ করে? (How it works?)

* **`<?php ... ?>`**: এটি হলো পিএইচপি-র ওপেনিং এবং ক্লোজিং ট্যাগ। এর ভেতরেই কোড লিখতে হয়।
* **`phpinfo();`**: এটি একটি বিল্ট-ইন ফাংশন। এটি যখন কল করা হয়, তখন এটি আপনার সার্ভারে ইনস্টল করা পিএইচপি-র ভার্সন, এক্সটেনশন, এনভায়রনমেন্ট এবং সার্ভারের বিস্তারিত তথ্য একটি সুন্দর টেবিল আকারে প্রদর্শন করে।

---

### ৩. কিভাবে দেখবেন? (Steps to View)

১. ফাইলটি আপনার লোকাল সার্ভার (যেমন: XAMPP-এর `htdocs` ফোল্ডার) অথবা লাইভ সার্ভারে সেভ করুন।
২. আপনার ব্রাউজার ওপেন করুন।
৩. অ্যাড্রেস বারে টাইপ করুন: `localhost/info.php` (যদি লোকালহোস্টে থাকে)।
৪. আপনি একটি বিস্তারিত পেজ দেখতে পাবেন যেখানে আপনার পিএইচপি সেটআপের সব তথ্য থাকবে।

### একটি প্রয়োজনীয় সতর্কতা (Security Note)

> **সতর্কতা:** এই ফাইলটি আপনার সার্ভারের অনেক গুরুত্বপূর্ণ তথ্য (যেমন: পাথ, আইপি, কনফিগারেশন) প্রকাশ করে দেয়। তাই কাজ শেষ হয়ে গেলে ফাইলটি সার্ভার থেকে ডিলিট করে দেওয়া নিরাপদ।
