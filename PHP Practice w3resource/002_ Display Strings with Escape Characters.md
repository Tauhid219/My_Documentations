
Write a PHP script to display the following strings.

Sample String :
'Tomorrow I \'ll learn PHP global variables.'
'This is a bad command : del c:\\*.*'
Expected Output :
Tomorrow I 'll learn PHP global variables.
This is a bad command : del c:\*.* 


### মূল পিএইচপি স্ক্রিপ্ট

```php
<?php
// প্রথম স্ট্রিংটি প্রিন্ট করা
echo "Tomorrow I'll learn PHP global variables." . "\n";

// দ্বিতীয় স্ট্রিংটি প্রিন্ট করা
echo "This is a bad command : del c:\\*.*" . "\n";
?>

```

---

### বিস্তারিত ব্যাখ্যা (Detailed Explanation)

পিএইচপি-তে স্ট্রিংয়ের ভেতর কিছু বিশেষ চিহ্ন (যেমন: `\`, `'`, `"`) সরাসরি প্রিন্ট করতে গেলে সমস্যা হতে পারে। এজন্য আমরা **Escape Characters** ব্যবহার করি।

#### ১. প্রথম স্ট্রিং: `Tomorrow I'll learn...`

এখানে চ্যালেঞ্জ হলো `I'll` শব্দের মাঝখানের সিঙ্গেল কোট (`'`)।

* **সমাধান:** কোডটিতে পুরো স্ট্রিংটিকে **Double Quotes (`" "`)** দিয়ে আটকানো হয়েছে। যখন আপনি বাইরে ডাবল কোট ব্যবহার করবেন, তখন ভেতরে সিঙ্গেল কোট ব্যবহার করলে পিএইচপি সেটাকে সাধারণ টেক্সট হিসেবে ধরে নেয়। তাই এখানে কোনো ব্যাকস্ল্যাশ দেওয়ার প্রয়োজন পড়েনি।
* `"\n"` এর মাধ্যমে আউটপুট দেওয়ার পর কার্সর নতুন লাইনে চলে যায়।

#### ২. দ্বিতীয় স্ট্রিং: `del c:\*.*`

এখানে চ্যালেঞ্জ হলো ব্যাকস্ল্যাশ (`\`) চিহ্নটি।

* **সমস্যা:** পিএইচপি-তে ডাবল কোটের ভেতর একটি সিঙ্গেল ব্যাকস্ল্যাশ (`\`) মূলত কোনো বিশেষ নির্দেশ (যেমন `\n` মানে নতুন লাইন) বোঝাতে ব্যবহৃত হয়।
* **সমাধান:** আপনি যদি স্ক্রিনে একটি ব্যাকস্ল্যাশ দেখাতে চান, তবে আপনাকে ডাবল ব্যাকস্ল্যাশ (`\\`) লিখতে হবে। প্রথমটি দ্বিতীয়টিকে "Escape" করে, অর্থাৎ পিএইচপিকে বলে— "পরের ব্যাকস্ল্যাশটিকে কোড হিসেবে না দেখে সাধারণ টেক্সট হিসেবে প্রিন্ট করো।"
* এজন্যই কোডে লেখা হয়েছে: `c:\\*.*`, যা আউটপুটে দেখাচ্ছে: `c:\*.*`

### স্ট্রিং লেখার ৪টি পদ্ধতি (সংক্ষেপে)

আপনার প্রশ্নে চারটি পদ্ধতির কথা উল্লেখ আছে, যা পিএইচপি ডেভেলপারদের জানা খুব জরুরি:

1. **Single Quoted (' '):** সবচেয়ে সাধারণ পদ্ধতি। এর ভেতর ভ্যারিয়েবল কাজ করে না এবং এটি ব্যাকস্ল্যাশকে সাধারণ টেক্সট হিসেবে দেখে।
2. **Double Quoted (" "):** এটি অনেক শক্তিশালী। এর ভেতর ভ্যারিয়েবল সরাসরি লেখা যায় (যেমন: `"Hello $name"`) এবং এটি সব ধরণের Escape Character প্রসেস করতে পারে।
3. **Heredoc:** বড় আকারের প্যারাগ্রাফ বা এইচটিএমএল কোড লেখার জন্য এটি ব্যবহার করা হয় যেখানে ডাবল কোটের সুবিধা পাওয়া যায়।
4. **Nowdoc:** এটি অনেকটা সিঙ্গেল কোটের মতো, তবে বড় টেক্সট ব্লকের জন্য ব্যবহৃত হয়। এর ভেতরে কোনো কোড প্রসেস হয় না।

### আপনার জন্য টিপস

আপনি যদি কমান্ড লাইনে (Terminal) কোডটি রান করেন তবে `\n` নতুন লাইন তৈরি করবে। কিন্তু যদি ব্রাউজারে রান করেন, তবে নতুন লাইনের জন্য `\n` এর পরিবর্তে `<br>` ট্যাগ ব্যবহার করতে হবে।
